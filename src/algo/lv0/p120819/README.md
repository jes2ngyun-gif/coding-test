| 개념         | 사용 이유            |
| ---------- | ---------------- |
| 정수 나눗셈 `/` | 몇 잔 살 수 있는지 구하기  |
| 나머지 `%`    | 돈이 얼마나 남는지 구하기   |
| 배열 `int[]` | 결과 2개를 한 번에 반환하기 |

예:
```
money = 15000
```
15,000원으로 5,500원짜리 커피를 사면
```
15000 / 5500 = 2
15000 % 5500 = 4000
```
결과:
```
[2, 4000]
```

---
### 코드를 작성하기 전 생각하는 순서
1 무엇을 구해야 하는가?
→ 마실 수 있는 아메리카노 수, 남는 돈

2 필요한 변수는 무엇인가?
→ 커피 가격 5500, 잔 수, 남은 돈

3 반복문이 필요한가?
→ 필요 없다. 계산 한 번이면 끝난다.

4 조건문이 필요한가?
→ 필요 없다. 제한사항에서 money는 0보다 크다고 했기 때문.

5 결과를 어떻게 반환할 것인가?
→ int[] 배열에 잔 수와 남은 돈을 담아서 반환한다.
