#### 배열 + 반복문 + 조건문 + 나머지 연산자%

#### [짝수 개수, 홀수 개수] 를 배열로 반환해야 함.

예:
```
[1, 2, 3, 4, 5]
```
EVEN → 2, 4 → 2개

ODD → 1, 3, 5 → 3개

결과:
```
[2, 3]
```

---
| 개념       | 사용 이유           |
| -------- | --------------- |
| 배열       | 여러 숫자를 저장       |
| for문     | 배열을 처음부터 끝까지 확인 |
| if문      | 짝수인지 홀수인지 판단    |
| `%`      | 2로 나눈 나머지 확인    |
| int[] 반환 | 결과 2개를 배열로 반환   |

### 코드를 작성하기 전 생각하는 순서
1 무엇을 구해야 하는가?
→ 짝수의 개수와 홀수의 개수

2 필요한 변수는 무엇인가?
→ evenCount, oddCount

3 반복문이 필요한가?
→ 필요하다. 배열 안의 숫자를 전부 확인해야 함.

4 조건문이 필요한가?
→ 필요하다. 숫자가 짝수인지 홀수인지 나눠야 함.

5 결과를 어떻게 반환할 것인가?
→ {evenCount, oddCount} 형태의 배열로 반환한다.
